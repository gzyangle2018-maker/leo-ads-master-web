导出位置与保存路径
亚马逊卖家平台后台路径
1. 品牌分析报表：卖家平台 > 品牌 > 品牌分析 > 搜索词 > 选择报表类型 > 下载
2. 业务报告：卖家平台 > 报告 > 业务报告 > 选择子商品/父商品 > 选时间范围 > 下载
3. 广告报表：广告后台 > 广告活动 > 商品推广/品牌推广 > 选择报表类型 > 日期范围 > 下载

ERP路径（优卖云 / 赛狐）
ERP > 广告管理 > 搜索词报告 > 输入目标ASIN > 导出汇总/明细

本地保存建议
在电脑桌面或D盘创建固定文件夹，例如：D:\AmazonReports\2026-05\
命名规范
格式：YYYYMMDD-报表类型-范围-[ASIN].csv
示例：20260508-SP-SearchTerm-30d-B08N5WRWNW.csv
⚠️ 禁止使用中文字符命名文件（除ASIN外），禁止留空格，用短横线-连接。

搜索词处理规则
条件动作
搜索词Orders≥2且ACOS<目标ACOS加入精准关键词
搜索词Orders≥2且CVR高同步加入Phrase/Exact
搜索词Clicks≥10且Orders=0加入否定精准候选
搜索词Spend≥单品毛利×1.5且Orders=0强制否定或暂停
搜索词相关性低直接否定精准
搜索词相关性高但未转化降价观察，不马上否定
搜索词为竞品品牌词单独建竞品Campaign，不混在自动广告里
搜索词为核心大词不轻易否定，先降价、拆组、看Placement
竞价调整规则
条件动作
ACOS 0–10%Bid +15%到+25%
ACOS 10–20%Bid +5%到+15%
ACOS接近目标保持
ACOS高于目标20%–50%Bid -10%到-20%
ACOS高于目标50%+Bid -20%到-40%
Clicks高、无订单降价或否定
曝光低、点击低、相关性高小幅加价
曝光高、CTR低检查主图、价格、标题、广告位
点击高、CVR低检查Listing、价格、Review、Coupon
预算规则
条件动作
Campaign ACOS<目标且预算花完预算+30%到+100%
Campaign ROAS高且Lost Budget高预算+50%
Campaign ACOS高且预算花完预算不加，先降bid/否词
Campaign花不出去不盲目加预算，先看bid、相关性、关键词量
秒杀/Prime Day/黑五设置Schedule Budget Rule
稳定盈利Campaign设置Performance Budget Rule
广告位规则
广告位判断逻辑动作
Top of Search高CTR、高CVR、高CPC赚钱则加Placement Bid
Rest of Search中等流量，通常更稳定适合稳定放量
Product Pages竞品拦截、详情页流量ACOS高就降，不要硬烧
Amazon Business Placement企业购流量3C类可重点测试
竞价策略规则
竞价模式适用场景系统判断
Dynamic bids - down only新品测试、控制风险默认安全模式
Dynamic bids - up and down高转化、预算足、抢位只给成熟盈利词
Fixed bids想稳定拿量、避免系统过度压价核心精准词可用
Rule-based bidding有稳定转化数据后按ROAS guardrail自动化
广告系统诊断流程
Step 1：导入报表
SP/SB/SD Campaign → SP/SB/SD Targeting → SP/SB Search Term → SP Placement → Advertised Product → Purchased Product → Business Report → 库存/价格/Coupon/Review/Buy Box

Step 2：统一字段
统一date、campaign_id、ad_group_id、target_id、asin、sku

Step 3：计算指标
CPC、CVR、ACOS、ROAS、CPA、Profit After Ads

Step 4：打标签
赚钱词 / 亏损词 / 高点击无转化词 / 高曝光低点击词 / 高转化低曝光词 / 预算受限活动 / 广告位浪费活动 / ASIN拖后腿活动

Step 5：生成动作
加预算 / 降预算 / 加bid / 降bid / 暂停target / 否定搜索词 / 拓精准词 / 拆广告组 / 新建Campaign / 调整Placement
SP报表优先级与用途
报表粒度核心用途系统动作
Campaign ReportCampaign判断整个广告活动是否赚钱预算加减、活动开关、结构重组
Ad Group ReportAd Group判断广告组结构是否合理拆分广告组、合并无效组
Targeting ReportKeyword/ASIN/Category判断关键词/ASIN/类目投放表现加价、降价、暂停、否定
Search Term ReportCustomer Search Term找真实买家搜索词精准拓词、精准否词
Advertised ProductSKU/ASIN判断哪个产品值得继续推ASIN广告预算分配
Placement ReportPlacement判断广告位效率搜索首页加价、商品页加价/降价
Search Term Impression ShareSearch Term判断核心词广告曝光份额核心词抢量、份额防守
SB（品牌推广）广告特殊逻辑
SB重点不是只看ACOS，要分两套逻辑：

品牌防守：品牌词ACOS低、转化稳、预算不断
品牌拉新：竞品词/类目词ACOS可高，但要看New-to-Brand

SB报表清单：Campaign Report / Keyword/Targeting Report / Search Term Report / Placement Report / Purchased Product Report / New-to-Brand Metrics
SD（展示型推广）广告注意点
SD最大风险：容易吃掉自然单或品牌已有需求。系统要区分：

点击归因订单 / 浏览归因订单 / 品牌内halo销售 / 真实新增销售

SD报表清单：Campaign Report / Targeting Report / Advertised Product Report / Purchased Product Report / Audience Report
